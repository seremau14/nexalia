# Nexalia per Home Assistant

La plancia con agente per Home Assistant: stanze, comandi, energia, sicurezza, persone, scenari, raccolta differenziata e Casa 3D. Con la licenza completa hai anche l'accesso da fuori casa, senza VPN.

Sito: **https://nexaliahome.com**

## Installazione

[![Aggiungi il repository a Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fseremau14%2Fnexalia)

Oppure a mano:

1. In Home Assistant apri **Impostazioni › App** (componenti aggiuntivi) e poi **Store delle app**.
2. Dal menu in alto a destra (⋮) scegli **Repository** e aggiungi:
   ```
   https://github.com/seremau14/nexalia
   ```
3. Cerca **Nexalia**, premi **Installa**, poi **Avvia**, e attiva **Mostra nella barra laterale**.

Serve Home Assistant OS oppure Home Assistant Supervised, cioè le installazioni con le app. La prima installazione richiede qualche minuto.

La guida completa si trova nella scheda **Documentazione** dell'app in Home Assistant.
